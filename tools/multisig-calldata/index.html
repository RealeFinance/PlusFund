多签调用数据生成器

选择方法并填写参数，按方法权限生成 Safe 可提交的交易数据。编码在浏览器本地完成。

1. 合约与方法

选择方法将显示所需权限和调用路径
自定义 ABI 无法从 ABI 推断 Solidity 权限。请根据合约源码选择直调或 Timelock；未识别的方法默认直调。

2. 调用路径与 Timelock

排期与执行交易会使用相同的 Salt。自动生成后可在此查看并复制。
PlusFund 默认规则：DEFAULT_ADMIN_ROLE 方法经 Timelock；PLUSFUND_ADMIN、POOL_ADMIN_ROLE、黑名单管理员方法由多签直接调用。普通业务及只读方法也可直调。部署实例若配置不同，请按链上角色持有人覆盖路径。

3. Safe 交易数据

交易 JSON
内部调用 Calldata / 执行交易

Timelock 模式：提交 Schedule JSON，延迟结束后提交 Execute JSON。两笔交易使用相同 target、value、calldata、predecessor 和 salt。Safe 字段采用 to / value / data 格式。
